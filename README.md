## 🔄 How I think about an incident

```mermaid
flowchart LR
    A([🔍 Detect]) --> B([⚖️ Triage])
    B --> C([🧪 Analyse])
    C --> D([🧱 Contain])
    D --> E([📝 Report])
    E --> F([📈 Improve])
    F -.-> A
```

Clear documentation matters as much as the technical analysis: a good report lets someone else act on it quickly.
